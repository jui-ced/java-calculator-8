# 문자열 덧셈 계산기 (String Calculator)
입력된 문자열에 포함된 숫자들을 구분자를 기준으로 분리하여 더하는 프로그램입니다.
쉼표(,) 또는 콜론(:)을 기본 구분자로 사용하며, 커스텀 구분자를 지정할 수 있습니다.

--- 

## 구현 기능 목록
- [x] 입력 문자열이 비었을 때 0을 반환한다.
- [x] 쉼표(,) 또는 콜론(:)을 구분자로 인식한다.
- [x] `//`과 `\n`사이에 위치하는 문자를 커스텀 구분자를 인식한다.
- [x] 커스텀 구분자와 기본 구분자를 동시에 처리할 수 있다.
- [x] 특수 문자도 커스텀 구분자로 지정할 수 있다. 
- [x] 구분자를 기준으로 분리한 숫자의 합을 계산한다.
- [x] 잘못된 입력 형식 또는 유효하지 않은 값이 들어오면 예외를 발생시킨다.


## 예외 처리
- 빈 문자열 또는 `null` 입력 시 `0`을 반환한다.
- 숫자가 아닌 값이 포함된 경우 `IllegalArgumentException`을 발생시킨다.
- 0 또는 음수가 포함된 경우 `IllegalArgumentException`을 발생시킨다.
- 커스텀 구분자 형식이 올바르지 않은 경우 `IllegalArgumentException`을 발생시킨다.
- try-catch 블록을 통해 예외 발생 시 프로그램이 비정상 종료되지 않도록 처리한다.
